## ✨ الجديد في v3

- 🎨 **أيقونة جديدة احترافية** (شعار اللهب الزجاجي ثلاثي الأبعاد)
- 🔄 **زر مزامنة عائم قابل للسحب** — اضغط = تحديث، اضغط مطوّل = شاشة "عن التطبيق"
- 📋 **قائمة منبثقة عند الضغط:**
  - تحديث الموقع (إعادة تحميل سريعة)
  - مسح الكاش وإعادة التحميل (لجلب آخر تحديثات Lovable نهائياً)
  - معلومات المطور
- 👤 **شاشة "عن التطبيق"** — فيها بياناتك (اضغط على الرقم يتصل، اضغط على الإيميل يفتح البريد)
- 🖨️ **طباعة حرارية مباشرة** على Sunmi V2 وأي جهاز يدعم بروتوكول Sunmi Inner Printer
- 📲 **يحفظ جلسة تسجيل الدخول** حتى بعد مسح الكاش
- ⚙️ **متوافق مع طابعات شبيهة بـ Loyverse** (طابعة حرارية داخلية)

## 🚀 خطوات بناء APK

### 1. ارفع الملفات على GitHub
- فك ضغط `GasTechPOS-android-wrapper-v3.zip`
- ادخل **جوا** مجلد `GasTechPOS`
- ارفع **محتوياته** (app/, gradle/, build.gradle, codemagic.yaml, ...) لمستودع GitHub

### 2. شغّل البناء على Codemagic
- Start new build → Branch: `main` → Workflow: `android-apk-build`
- استنى 6-10 دقائق

### 3. وقّع الـ APK
- حمّل `app-release-unsigned.apk` من Artifacts
- روح https://www.apksigner.com → ارفع → Auto-generate keystore → Sign APK

### 4. ثبّت على جهاز Sunmi
- انقل APK للجهاز → ثبّت → افتح التطبيق

## 🔄 المزامنة بعد التثبيت

أي تعديل تعمله في Lovable يظهر فوراً في التطبيق:
- **Pull-to-refresh** (سحب للأسفل) = تحديث عادي
- **اضغط زر 🔄 العائم** = قائمة فيها 3 خيارات (تحديث / مسح كاش / عن التطبيق)
- **اضغط مطوّل على زر 🔄** = فتح شاشة "عن التطبيق" مباشرة

**لن تحتاج بناء APK جديد إلا في حالات نادرة** (تغيير رابط الموقع، أو إضافة دعم طابعة جديدة).

## 🖨️ التحقق من الطباعة

1. افتح التطبيق على جهاز Sunmi
2. روح إعدادات → الإيصال → اضغط Test Print
3. لازم يطبع فاتورة تجريبية فوراً

لو ظهرت رسالة "خدمة طابعة Sunmi غير متصلة":
- تأكد من تشغيل خدمة الطابعة الداخلية في إعدادات Sunmi
- أعد تشغيل الجهاز
